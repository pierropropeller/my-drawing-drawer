## 批次 21（2026-10-26，snackbar 規格＋編輯坑換封面）
- **D-114** **Snackbar（底部提示）統一規格**（之前沒有畫稿，實裝版會擋住按鈕）： ✅ commit bc4bafe
  - **樣式**：反色。淺色模式 `#2B2622` 底＋白字；深色模式 `#F2ECE4` 底＋`#2B2622` 字。圓角 14，左右各留 16px，內距 12×16，左邊可放 18px icon（成功＝勾），右邊可放一個文字動作（例如「復原」，主色）。
  - **位置**：**永遠浮在底部固定元件的上面，不可以蓋住任何按鈕**：
    - 有導覽列的頁面：導覽列上方 12px。
    - 有底部動作列（多選）或固定底部按鈕的頁面：在那一排上方 12px。
    - 都沒有：距離螢幕底部（含系統手勢區）16px。
    - 鍵盤彈出時跟著浮在鍵盤上方。
    - **右下「＋」浮動按鈕**：snackbar 出現時「＋」跟著往上推，停在 snackbar 上方 12px，snackbar 消失後滑回（Flutter 把 SnackBar 交給同一個 Scaffold 就會自動推 FAB）。
    - 實裝版仍有三處蓋住按鈕：年度回顧排版的「儲存至相簿」、預覽頁底部動作列、列表頁的「＋」。示意圖見 canvas `SnackbarSpec`。 ✅ commit b983cad
  - **時間**：3 秒自動消失；有「復原」時 5 秒。可向下滑走。同時只顯示一則，新的取代舊的。
  - **什麼時候用**：只用在「動作已經生效、而且人留在原頁」的情況。例如：預覽頁「設為封面」、坑內長按選封面、多選批量操作（「已刪除 3 張」＋復原、「已移動 5 張」）、分享匯入「已加入」。
